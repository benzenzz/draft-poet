## Mascot size and hover

All three existing Bé Cúc images are1.30×their previous display dimensions, preserving aspect ratio, facial artwork and exact foot/ground point. Heights:75→97.5,72→93.6and74→96.2SVGunits. Source image files, locations and Bé Mầm are unchanged.

Transform ownership is separate:

```text
build-item position/entrance
  object-hover / object-art
    flower-hover (new one-shot scale/lift)
      character-body (existing idle sway)
        original image
  object-hit → original image only, at fixed enlarged-base coordinates
```

The hit silhouette references the image itself, not its animated ancestors. It stays at the new base size, preventing the hover target from chasing the lifted/scaled drawing. Shadows remain grounded. Flowers are excluded from the old generic7pxCSS hover lift so two systems do not compete.

Pointer entry:75ms subtle squash,220ms growth/overshoot to1.205and10unit lift, then300ms settling to1.17and7unit lift. It holds there rather than looping. Exit returns to1/y0in300ms. Rapid reversal kills the previous owned tween and continues from its current state. Idle sway retains its original wrapper/timeline.

Reduced motion uses immediate1.035scale with no vertical bounce; exit is immediate. Touch does not activate hover. Decorative mascots gain no button roles, pointer cursor, focus stops or action. Pause, handoff, offscreen/reduced transitions and controller cleanup reset/kill dedicated hover transforms. Event listeners use the existing AbortController lifecycle.
